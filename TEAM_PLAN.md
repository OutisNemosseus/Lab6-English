# Three-person work plan

Divide responsibility into two complete experimental workflows plus independent simulation and integration. This keeps each set of measurements with the person who analyzes it.

| Member | Primary questions | Required deliverables | Handoff |
| --- | --- | --- | --- |
| A RC lead | Q3.1-3.7 and Q3.9; coordinate Q3.8 with C | Wiring photograph, derivation, numerical expressions, hand sketches, 11-point measurements and cursor captures, Excel plots, RC comparison | Share component values and theory with C early. Receive simulation results and finish Q3.9. |
| B RL lead | Q4.1-4.7 and Q4.9; coordinate Q4.8 with C | The equivalent RL evidence; record inductor DC resistance and investigate nonideal behavior | Share component values and theory with C early. Receive simulation results and finish Q4.9. |
| C Simulation and integration lead | Q3.8, Q4.8, Q1.1; assist Q3.7/Q4.7 and review Q3.9/Q4.9 | Both AC simulations, Excel chart support, theory/measurement overlays, appendix organization, report assembly, question-by-question checks | Run ideal simulations early. Once measured data arrive, check signs, units, cutoff points, discrepancies, and evidence completeness. |

All members should understand the derivations, wiring, and results. C owns substantial simulation, chart review, and integration work; this role is more than copying files.

If only one ADALM2000 is available: A measures RC while B helps read cursors and record data; C runs both ideal simulations. Then B measures RL while A records. Finish with a joint review.

If Tong chooses RC, Tong takes role A. Member names, group number, leader, and actual date remain unassigned until confirmed.

## Handoff requirements

1. A and B provide each original capture, actual frequency, Vin/Vout RMS and Vpp, cursor times or delta t, and signed phase.
2. C uses the same measured data for all charts. Resolve discrepancies with the measurement owner before changing values.
3. A and B approve their own Q3.9/Q4.9 comparisons. C verifies every question, figure, appendix, and required capture.
4. All members confirm Q1.1. The designated group leader handles final submission; this plan does not appoint one.
